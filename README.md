# Secure Coding — Green Belt

An offline-first lesson game for secure coding practice: twelve CWE-based flaw → defence
pairs. Each lesson shows the vulnerable code, asks which change removes the flaw, and then
reveals the control that does.

Open it at `secure-coding-green-belt.html` (self-contained; works offline in any browser).

Scoring: a lesson solved on the first pick scores 100; solved after a miss scores 50.

Lesson content is adapted from the OWASP SecureCodingDojo Green Belt (Apache-2.0);
code excerpts have been rewritten and the defence pairings authored for this pack.
