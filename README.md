# Secure Coding — Green Belt

An offline-first lesson game for secure coding practice, in **two belts**: a **web & CWE belt**
(12 lessons) and a **mobile belt** (the OWASP Mobile Top 10, 10 lessons). Each lesson shows the
vulnerable code or artefact, asks which change removes the flaw, and then reveals the control
that does.

Each belt carries its own progress and a **coverage map** of the framework it is measured
against — lit as you solve, and showing the categories the belt does *not* cover rather than
hiding them.

Open it at `secure-coding-green-belt.html` (self-contained; works offline in any browser).

Scoring: a lesson solved on the first pick scores 100; solved after a miss scores 50.

The web belt's lesson content is adapted from the OWASP SecureCodingDojo Green Belt
(Apache-2.0); code excerpts have been rewritten and the defence pairings authored for this pack.
The mobile belt is adapted from the M4 SN50 "Own the Device" lab game; the OWASP Mobile Top 10
is OWASP's own framework.
